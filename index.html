This generator uses a square grid. Some pairs produce uneven lettering or many small pieces. The piece count and timing help compare results.

How It Works

Both names are drawn with the same total area. The generator finds connected pieces that fit in each name, allowing them to move and rotate. Every square is used once in each arrangement.

The puzzle is generated in your browser. Shared links contain the names and a seed so another browser can recreate the same pieces.
